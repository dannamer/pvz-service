# Тестовое задание для стажёра Backend-направления (весенняя волна 2025) - Сервис для работы с ПВЗ

## Описание

Этот проект представляет собой backend-сервис для работы с пунктами приёма заказов (ПВЗ), который включает регистрацию, авторизацию пользователей, управление ПВЗ и приёмками товаров.

### Выполненные задачи:

- **Трёхслойная архитектура**: Реализована чистая архитектура с разделением бизнес-логики, обработкой данных и взаимодействием с базой данных.
- **Логирование**: Логирование ошибок 500 с использованием `zerolog`. В остальных случаях используется стандартное логирование Gin.
- **Тесты**: Написан интеграционный тест, который проверяет работу основных функциональных блоков системы.
- **Docker Compose**: Для запуска проекта используется Docker и Docker Compose:
  - **Docker** используется для сборки сервиса.
  - **Docker Compose** используется для развертывания как сервиса, так и базы данных.
- **Генерация кода с помощью `ogen`**: Использован инструмент `ogen` для автоматической генерации кода по OpenAPI спецификации.
- **Паттерн "Один файл — одна функция"**: В проекте использован принцип "Один файл — одна функция", что улучшает читаемость и поддержку кода, позволяя легко добавлять или изменять функциональность без нарушения структуры проекта.
### Стек технологий

- **Язык программирования**: Go
- **Web-фреймворк**: Gin
- **База данных**: PostgreSQL (с использованием SQL-запросов без ORM)
- **Логирование**: Для логирования ошибок 500 используется `zerolog`. В остальных случаях используется стандартное логирование Gin.
- **Docker**: Используется для сборки сервиса. Docker Compose используется для развертывания сервиса и базы данных.
- **Генерация кода**: Для автоматической генерации кода по OpenAPI схеме использован инструмент `ogen`.
